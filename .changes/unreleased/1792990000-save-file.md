title: The save file

`ge::save`: the save file (a checksummed header, the meta a menu lists first, tagged and versioned chunks, a directory), the state described once by `describe(io, T&)` for its writer and reader with `since` and `until` across versions, bulk copies of numbers and `GE_SAVE_PLAIN` types, refusals that name the file and the chunk, the `save-file` lab and `ge save inspect`.
