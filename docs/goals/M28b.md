Status: done

The movement knobs are console cvars (`engine/move/cvars.hpp`, `docs/movement.md` § Knobs as
cvars):

- `bind_knobs` binds every knob (47) as an owner prefix plus its name, by default `sv_` with the
  server's flags (`kServer | kServerInfo`), with the knob's kind, range, help and unit; the
  defaults are the bound row's values, so binding moves no bit of any preset.
- A client's own `set` of a server's knob is refused (`SetResult::server`), and the server's
  info carries the row to the client's spec (`apply_info`).
- `apply_cfg` runs a server cfg on a spec, each refused line named by file and line; the
  `move-strafe` and `move-trace` labs take it as `--cfg`, before `--set`.
- A cfg gives the same digest as `--set` with the same values on the straight hops, the strafe
  jumper and the double jump (`tests/move_cvars_test.cpp`).

`ge cvar ls` lists the knobs, units in the help, once a game binds them on its play console;
no game does yet (Fall Line has no character on foot). Shooter's Edge binds them under `sv_`
(M18e).
